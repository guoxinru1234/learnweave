## if

if 是 Python 数据分析中的核心概念。本节详细讲解其定义、用法和常见场景，帮助学习者掌握正确的使用方式。

### 基本概念

if 的基本概念包括其语法形式、适用场景和与其他概念的关联。正确理解和使用 if 可以显著提升代码的可读性和效率。

### 使用示例

```python
for i in range(5):
    if i % 2 == 0:
        print(f"{i} is even")
    else:
        print(f"{i} is odd")
count = 0
while count < 3:
    count += 1
try:
    result = 10 / 0
except ZeroDivisionError as e:
    print(f"Error: {e}")
```

### 常见错误

- 注意 if 与相似功能的区别，避免混淆
- 运行时常见报错：检查数据类型、导入模块和语法正确性

- 动手实践：修改上述示例代码并观察输出变化
